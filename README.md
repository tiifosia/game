# 비어퐁 땅따먹기

비어퐁으로 얻은 화살표로 5×5 판 위의 말을 움직여 (5,5)를 향해 가면서, 지나가는 칸마다 내 땅으로 만들고 상대 땅까지 빼앗아 더 많은 땅을 차지하는 2인 게임입니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. (설치 필요 없음)

## 조작

- 비어퐁에서 공이 들어간 컵의 방향을 **상 / 하 / 좌 / 우** 버튼(또는 키보드 방향키, WASD)으로 입력합니다. 최대 5개.
- 입력한 순서대로 이동합니다. 칩의 ◀ ▶ 로 순서를 바꾸고 ✕ 로 지울 수 있습니다.
- 판에 점선으로 이동 경로가 미리 표시되고, 판 밖으로 나가는 화살표는 `소멸`로 표시됩니다.
- **이동하기**(Enter)를 누르면 한 칸씩 이동하며 토큰이 놓입니다.

## 구현된 규칙

- 2인, 최대 8라운드 (라운드마다 선공 → 후공)
- 좌표 (x, y): 출발 (1,1), 도착 (5,5). 예) (1,1)에서 우→우→하 → (2,1), (3,1), (3,2)에 토큰
- 이동 가능한 화살표는 반드시 사용, 판 밖으로 나가게 되는 화살표만 소멸
- 들어간 칸마다 토큰 1개: 빈 칸이나 상대 토큰이 맨 위인 칸에는 쌓고, 내 토큰이 맨 위인 칸에는 쌓지 않음
- 두 말은 같은 칸에 있을 수 있음
- (5,5)에 먼저 도착하면 즉시 종료, 아니면 8라운드 후 종료
- 점수: 맨 위 토큰 주인이 그 칸 토큰 전부 × 500점, 먼저 도착한 플레이어 +2,000점
